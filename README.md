# miAi

Centro di comando personale, **locale e offline**: notizie, GitHub, idee,
progetti, task, CV, CyberQuest e altro. Tutti i dati restano sul tuo PC.

> Il README completo e la demo arrivano a breve.

## Avvio rapido
```
pip install -r requirements.txt   # se presente
python agent.py     # prima raccolta dati + genera app.html
python server.py    # avvia il server locale
```
Poi apri <http://127.0.0.1:8770/app>.
