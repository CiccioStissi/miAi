# miAi

*Read in: [Italiano](README.md) · **English***

**Personal command center — local, offline and privacy-first.**
A single dashboard that gathers news, GitHub trends, business ideas, projects, tasks,
CV analysis, a game to learn cybersecurity and much more. It runs entirely on your
PC: **no personal data ever leaves the computer or hits the network.**

> Personal, single-user project, designed for local use on `127.0.0.1`.
> Pluggable AI backend (local Ollama or any OpenAI-compatible endpoint).

---

## Philosophy

- **Offline-first**: the server listens only on `127.0.0.1`, no cloud service required.
- **Privacy by design**: your data (favorites, calendar, projects, CV) stays on disk; with a
  PIN set, storage is **encrypted at rest** (Fernet, key derived from the PIN via scrypt).
- **Zero build**: the interface is a single HTML file generated by Python and served by the
  standard library `http.server`. No Node, no bundler.
- **Generic and customizable**: on first run you choose which sections to show, which topics
  to follow, your interests and which AI model to use.

## Key features

| Area | What it does |
|------|--------------|
| **Today** | The best of every section filtered to today; pick-your-own tiles. |
| **Assistant** | Chat with the local AI that sees your data and **takes action** (open sections, add reminders/tasks, change theme…), with streaming replies. |

| **CV Editor (keep structure)** | Upload an existing CV (PDF): I extract sections and content in their original order, you edit **only the text** (with per-section "improve with AI", no fabrication) and I regenerate keeping the **same structure**. |
| **CyberQuest** | A leveled path to learn defensive cybersecurity by playing (quizzes + interactive mini-games). |
| **PDF Summary** | Summary, key points and questions from a PDF (paper, handout, contract). |
| **Interview Gym** | Realistic interview questions from your CV and target role. |
| **Cover Letter & Match** | CV ↔ job posting compatibility + a tailored cover letter. |
| **Calendar / Writing** | Deadlines with desktop alerts; rewrite/translate text with AI. |
| **Disk / PC** | Reclaimable space, cold files and duplicates; advice for your real hardware. |
| **AI Usage** | Tokens used by your AI agents (Claude Code, Codex, Gemini…), combined and per agent. |
| **Customize** | 30+ themes, AI model selection, PIN, auto-lock, backup/restore, auto-start. |

## Privacy & security

- Server bound to `127.0.0.1`; **Host** and **Origin** validation (anti CSRF / DNS-rebinding).
- **Content-Security-Policy** with `connect-src 'self'` (blocks XSS exfiltration),
  `Referrer-Policy: no-referrer`, `X-Content-Type-Options: nosniff`.
- **Optional PIN** enforced server-side (401 on data until you unlock) + **auto-lock**.
- **Storage encryption at rest** with Fernet (key from scrypt over the PIN).
- The modules that reach the network read **only public sources** (GitHub, Google News RSS,
  CoinGecko, CISA) and never send personal data.

## Languages

Switch the whole interface language via **argos-translate** (**offline** neural translation):
after a one-time language-pack download, translation is local, instant (cached on disk) and
covers every text. AI-generated content follows the chosen language.

## Tech stack

- **Python** (standard library `http.server`, `sqlite3`), no web framework.
- **SQLite** for the data collected by the agent.
- **Interface**: a single `app.html` generated from a Python template (inline CSS/JS).
- **AI**: [Ollama](https://ollama.com) locally by default, or any OpenAI-compatible endpoint
  (LM Studio, llama.cpp, vLLM, cloud API).
- **Translation**: [argos-translate](https://github.com/argosopentech/argos-translate) (offline).
- **Security**: `cryptography` (Fernet), `keyring` for the GitHub token (Credential Manager).

## Quick start

```bash
pip install -r requirements.txt

python agent.py     # first data collection + generates app.html
python server.py    # start the local server
```

Open **http://127.0.0.1:8770/app**.

> AI features need [Ollama](https://ollama.com) running (`ollama serve`) with a model pulled
> (e.g. `ollama pull qwen2.5:3b-instruct`), or configure another backend from the **AI Model**
> section.

On Windows you can enable **auto-start** at login from the app's Settings.

> Exporting the **CV to PDF** from the CV Builder requires a LaTeX distribution installed
> (MiKTeX or TeX Live). Without it, you can still download the `.tex` source (also compilable
> on Overleaf).

## Architecture at a glance

```
agent.py      data collection (GitHub, news, disk, hardware) -> SQLite
ui.py         generates app.html (single-file) from the payload
server.py     http.server on 127.0.0.1: API + serving the app + auth/PIN + encryption
llm.py        pluggable AI backend (Ollama / OpenAI-compatible), queue + streaming
mt.py         offline UI translation (argos-translate) with on-disk cache
```
